# Description

Removes the delay before the localized text appears on runestones: the text is shown immediately
instead of fading in a few seconds after the runic text.

In the base game, reading a runestone plays a reveal animation. The runic text is shown first, and
the translated text only fades in at the end of the animation, so you have to wait a few seconds
before you can read it. This mod skips that wait: the text is fully visible the moment you read the
runestone.

# Installation

This mod is client-side only. There is no configuration file.

## Using a mod manager (recommended)

You can install the mod using Vortex (nexusmods.com) or Gale (hexium.gg).

## Manual

Install BepInExPack for Valheim. Copy the DLL file to
`Steam\steamapps\common\Valheim\BepInEx\plugins\`
